# Epics and features

Epics 1 to 3 are MVP #1 (closed beta). Epic 4 is the MMP (public launch) and is out of scope for this repo for now.

Every feature also meets `BANKING_PRD_TECHNICAL_REQUIREMENTS.md`: encrypted local data, biometric unlock with a 5-minute lock, privacy blur, idempotent and atomic writes, and the four UI states.

## Epic 1: Easy Start

| Feature | User story |
|---|---|
| Goal picker | As an adult with ADHD opening the app for the first time, I want to pick one simple goal, so that the app sets itself up around what I care about. |
| Optional bank linking | As a user unsure about sharing bank access, I want to link my bank or type my balance, so that a trust decision does not block me. |
| Automatic bill detection | As a surprise-hit spender, I want the app to find my recurring bills, so that I don't have to remember and enter them. |
| Smart default categories | As an overwhelmed restarter, I want ready-made spending categories, so that I can skip building a budget from scratch. |
| Step progress and autosave | As a user who gets distracted easily, I want setup to show steps left and save my place, so that I can come back without starting over. |

## Epic 2: Money at a Glance

| Feature | User story |
|---|---|
| Safe-to-spend number | As an adult with ADHD, I want one number showing what I can safely spend after bills and savings, so that I don't do the math in my head. |
| Visual buckets | As an adult with ADHD who finds lists of numbers hard to hold in mind, I want my money shown as Spending, Bills and Savings buckets that fill and empty, so that I can see where it is at a glance. |
| Home-screen widget | As a user for whom money is out of sight, out of mind, I want a home-screen shortcut to safe-to-spend and quick add, so that I check it without hunting for the app. The amount is hidden ("Tap to view") unless I choose to show it. |
| Automatic transaction import | As a user who can't keep up with logging, I want transactions to import and sort themselves, so that the app stays accurate when I forget it. |
| Quick add | As a user who pays cash sometimes, I want to log an expense in two taps, so that logging actually happens. |
| Bill countdown | As a surprise-hit spender, I want to see bills due in the next 7 days, so that nothing catches me off guard. |

## Epic 3: Calm, Guilt-Free Habits

| Feature | User story |
|---|---|
| Fresh start | As an overwhelmed restarter, I want to clear my backlog with one tap after a break, so that catching up never stops me from coming back. |
| Gentle weekly check-in | As a user who struggles with routines, I want one short weekly check-in at a time I choose, so that I stay on track without daily effort. |
| Snoozable reminders | As a user who ignores nagging alerts, I want reminders I time and snooze myself, so that they help instead of annoy. |
| Pause before purchase | As a surprise-hit spender, I want an optional pause above an amount I set, so that I can stop an impulse buy in time. |
| Focus Mode | As a user overwhelmed by busy screens, I want a mode that hides all but the current task, so that I finish what I opened the app to do. |

## Epic 4: Shared Support and Progress (MMP, later)

Couples mode, coach sharing, savings goals with visual progress, body-doubling check-ins, new recurring charge alerts.
