# AI Development Residency

Coursework for the AI Development Residency at Tech Fleet: four weeks of using AI tools to plan, design and build the **ADHD Financial App**, a budgeting app for adults with ADHD. It shows what is safe to spend in one glance, and welcomes people back after a break without guilt.

- **Live app:** [aidevelopmentresidency.vercel.app](https://aidevelopmentresidency.vercel.app)
- **Blog:** [AI Development Resident @ Tech Fleet](https://kind-football-d24.notion.site/AI-Development-Resident-Tech-Fleet-4130c062e37d81a9a766d5fb3f9d71ad), a week-by-week write-up of the process and the thinking behind it

| Week | Folder | Summary |
|---|---|---|
| 1 | [Week 1 - Coding Challenge](Week%201%20-%20Coding%20Challenge) | 10 Claude Code agent skills (4 design, 6 coding), with sources, descriptions and a safety review. |
| 2 | [Week 2 Coding Challenge](Week%202%20Coding%20Challenge) | 9 market research and product management skills for writing a PRD for an ADHD-friendly budgeting app. |
| 3 | [Week 3 Coding Challenge](Week%203%20Coding%20Challenge) | Setup for building the ADHD budgeting app MVP: `CLAUDE.md`, PRD summary, epics, banking UX and security requirements, an MVP build plan and technical requirements document, and 22 skills: product (MVP scope, ADHD UX, accessibility, safe-to-spend math) and engineering (8 official Expo skills, dev workflow, testing, local data, banking security, security and privacy, reminders, Supabase, React Native performance, debugging, verification). |
| 4 | [Week 4 Coding Challenge](Week%204%20Coding%20Challenge) | The MVP: an Expo app (Android, iPhone and web) in [`ADHDbudget-App`](Week%204%20Coding%20Challenge/ADHDbudget-App), redesigned with Apple's iOS 26 UI kit and kept accessible for ADHD users. Accounts and data in Supabase with per-person security, published on Vercel. Also 3 AI review agents (engineer, accessibility, communications), 5 new design skills, 6 [Architecture Decision Records](Week%204%20Coding%20Challenge/docs/adr), a [database diagram](Week%204%20Coding%20Challenge/docs/database-diagram.md) and 96 automated tests. |

> The assignment asked for a folder named "Week 1: Coding Challenge". Windows doesn't allow `:` in folder names, so it's named `Week 1 - Coding Challenge` to keep the repository usable on every operating system.
